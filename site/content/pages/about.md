**Felix Homelab** 是一个自托管的一站式站点与服务平台：官方内容由站长维护，社区内容由
注册用户创作；同时提供 Git 托管、私有云盘与多租户 AI Agent 等自建服务。

## 这里有什么

- **官方博客与项目**：文章、笔记与开源项目的记录，随仓库版本化；
- **社区**：注册即可投稿文章、项目与游戏内容，用 `#分类` 自由组织，发布即公开，违规会被下架；
- **光遇**：攻略与画廊、代跑说明与评价，以及独立的游戏社区；
- **自建服务**：Forgejo（Git 托管）与 OpenCloud（文件同步 / 分享），后续将与本站统一账号登录；
- **AI Agent**：为授权账号提供独立的在线 AI 工作台（试点）。

## 团队

Felix Homelab 由站长与分工管理员共同维护：

- **站长 / 维护**：Felix —— 架构、开发与日常运维；
- **社区管理员**：审核评论与社区内容；
- **光遇管理员**：维护光遇板块、代跑展示与评价；
- **Agent 管理员**：开通与管理多租户 AI Agent。

权限按后台角色细分，可在账号后台按需授予。想加入维护，欢迎先参与社区。

## 联系

- 在文章下评论，或直接发布社区内容——登录后即可；
- 代码与问题：[FelixHomelab/felix-homelab](https://github.com/FelixHomelab/felix-homelab)，欢迎提 Issue；
- 本站不发邮件，也没有联系表单——收不到的表单比没有表单更糟。

## 技术

**Leptos + Axum + SQLite** 的 Rust 全栈站点，跑在基于 **Podman + Quadlet** 的 rootless
自托管工作站（Caddy / Forgejo / OpenCloud / 定时备份与自愈）上。设计取舍与踩过的坑
记在仓库的 `DESIGN.md` 与 `TODO.md`。
